Privacy Policy

Champions Dex (Windows desktop, Microsoft Store)

Effective date: 5 November 2026

Unofficial fan app. Champions Dex is an independent companion for Pokemon Champions planning. It is not affiliated with, endorsed by, or sponsored by Nintendo, The Pokemon Company, Game Freak, or Creatures Inc.

This page describes how the Windows desktop build of Champions Dex ("the app", "we") handles information. It is written for the Microsoft Store product. Mobile (Android / iOS) builds may include additional features; those mobile-only features are marked below as not applicable to this Windows Store build.

Summary

  • No account or sign-in is required or offered in the Windows Store build.
  • Teams, Pokemon Builder builds, match logs, settings, and cached reference data stay on your PC by default.
  • The app may download public reference JSON and artwork over HTTPS and cache them locally so the app can work offline.
  • No ads and no sale of personal data for advertising in this app.
  • Optional: if you use Send feedback, you may type a message and an optional email. That content is sent to Formspree so the maintainer can read it.
  • Not in this Windows Store build: AI Coach, in-app purchases / RevenueCat, screenshot OCR import, and Android battle overlay.

1. Information stored on your device

The Windows app stores, among other things:

  • Saved teams and related team-builder state (local database such as Hive), including local identifiers (UUIDs).
  • Saved Pokemon Builder builds (single-Pokemon loadouts) in Hive, also keyed by local UUIDs.
  • Match logger entries (format, participating teams or build snapshots, results, notes) for your personal history inside the app.
  • App settings and preferences (for example SharedPreferences), including theme and an optional backup export folder path when you choose a folder for desktop backups.
  • Cached copies of public reference files (Pokemon, moves, items, abilities, image manifest) and cached images (for example sprites) so the app can work offline after the first download.

Uninstalling the app removes application sandbox data on your PC, subject to how Windows handles backups and residual files. Files you exported (for example JSON backups in a folder you picked) remain under your control outside the app sandbox.

2. Network services used by the Windows build

2.1 Game reference data and artwork

To obtain and update Pokedex, move, item, and related reference data, the app requests static files over HTTPS from public hosts, including:

  • https://raw.githubusercontent.com/cycalo/Pokemon-Champions-Serribi-Scraper/main/data/
  • https://raw.githubusercontent.com/cycalo/Pokemon-Champions-Serribi-Scraper/main/images/

The upstream project documents that it mirrors Serebii.net material for Pokemon Champions. The GitHub repository path retains a misspelling ("Serribi") in the slug only; the URLs above are the live endpoints.

Supplementary Pokemon artwork may also be requested from https://raw.githubusercontent.com/HybridShivam/Pokemon/master/assets/imagesHQ/ and, for some mappings, raw.githubusercontent.com/PokeAPI/sprites. Those are ordinary image GETs, not account sign-ins.

GitHub and other hosts will see standard connection metadata that any HTTPS host would see (such as IP address and TLS metadata) while delivering the file. The app does not send your team names, notes, match logs, or saved rosters to those repositories as part of normal reference downloads.

You can delete cached JSON reference files from Settings using Clear cache and refresh data. Image caches may retain sprites until cleared by the system or the app's image cache.

2.2 Google Fonts

The app may use the google_fonts package for typography. Depending on platform behavior and cache state, font files may be downloaded from Google font endpoints over HTTPS. Those requests are not used for in-app advertising or cross-app tracking. See Google's own policies for how Google handles those requests.

2.3 Optional feedback (Formspree)

Settings includes an optional Send feedback action. If you use it, you can voluntarily send:

  • a category (idea, bug, or other),
  • a message you type,
  • an optional email so we can reply,
  • and the app version (no other device identifiers are intentionally attached by that form).

That content is submitted over HTTPS to Formspree (form endpoint configured in the app) and delivered to the maintainer's notification email. Do not include sensitive personal data you do not want transmitted to Formspree and the maintainer. See Formspree's privacy documentation for how they process submissions.

If you never use Send feedback, this path does not send that content.

2.4 Optional public announcements

If a given Windows build is compiled with Supabase URL and anon key dart-defines, the app may fetch public developer announcement rows (title, body, optional https link, timestamps) over HTTPS. No account is required for that read. The app does not send your teams, match logs, or saved rosters as part of that request. The last successful list and unread badge state may be stored locally. Builds compiled without those defines do not use this path.

2.5 Optional crash reporting (Sentry)

Some release builds may be compiled with a Sentry DSN. In those builds only, uncaught errors and limited performance traces may be reported to Sentry. Default builds distributed without that flag do not send telemetry to Sentry. Diagnostic reports can include technical context such as app version, device type, operating system version, and stack traces. They are not intended to collect free-text personal identifiers you type into the app.

2.6 Backup, restore, share, and Pokepaste import

On Windows you may pick a folder once, then Create backup writes JSON files of your saved teams and Pokemon Builder builds there. Match logs are not included in that backup format.

If you use Share or export features, content is passed to the destination app you choose. We do not control how those third-party apps process data.

Pokepaste import lets you paste Showdown-style team text. Parsing happens on your device against the local reference dataset. Pasted content is not transmitted to Champions Dex-operated servers as part of that feature path.

3. Features not included in this Windows Store build

The following appear in the broader ChampionsDex project or mobile apps, but are not applicable to the Windows Microsoft Store build described on this page:

  • AI Coach (Z.AI / GLM prompts, tool calls, and related traffic) - not shipped in this Windows Store product.
  • Purchases, credits, RevenueCat, Google Play Billing, Apple IAP, and account linking - not used in this Windows Store build. There is no in-app purchase flow for AI Coach credits here.
  • Screenshot OCR team import (gallery screenshots + on-device ML Kit) - unavailable on desktop; the app shows that the feature is mobile-only.
  • Android battle overlay (display over other apps / foreground service) - Android only; not present on Windows.
  • Mandatory or optional sign-in for core use - not offered in this Windows Store build.

4. What we do not do (by design)

  • No behavioral advertising or ad mediation SDKs in the described dependency set for this product.
  • No requirement to provide your name, email, phone number, or contacts. An email is optional only if you choose to include one on the feedback form.
  • No collection of precise location for advertising.
  • No use of advertising ID for profiling inside this app's own code paths described above.

5. Children's privacy

Champions Dex is a companion tool for planning teams in a video game. If you are a parent or guardian and have questions about your child's use of the app, please review this policy together with them. If you believe we should remove project-side content tied to a support channel you control, contact us using the details below.

6. Your choices

  • Export or delete device data: clear cache in Settings, delete teams in-app, remove exported backup files you created, or uninstall the app.
  • Feedback: do not use Send feedback if you do not want a message (or optional email) sent via Formspree.
  • Regional rights: depending on where you live, privacy laws may give you additional rights regarding personal data.

7. International users

If you use the app outside the country where the maintainer resides, information that travels over the network (for example reference downloads, optional Formspree feedback, optional announcements, or optional Sentry reports when enabled) may be processed according to this policy and the practices of those infrastructure providers.

8. Changes to this policy

We may update this policy from time to time. The effective date at the top will change when we do. Material changes will be reflected on this page and, when practical, in the in-app Privacy Policy text when the app is updated.
